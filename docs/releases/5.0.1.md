# BedWars2023 5.0.1 — Gameplay & Stability Update

This maintenance release fixes resource chest deposits, refreshes chest holograms
from configuration during games, and addresses dependency loading and player-data
persistence issues in this fork.

## Changes

- Determine normal chest ownership from the nearest team island within the configured island radius. Another team's first deposit can no longer claim your chest.
- Apply the same chest access rules to opening and depositing. Eliminated teams' chests remain accessible.
- Deposit into existing stacks and both halves of double chests. Keep partial-deposit leftovers in the held slot without duplicating items.
- Correct resource chest hologram height and line order. Apply text, colors, offsets, spacing and enable switches to active games with `/bw reload resourcechest`.
- Bundle the relocated Flow NBT library to fix `ClassNotFoundException: com.tomkeuper.bedwars.libs.flowpowered.nbt.Tag` on startup.
- Correct achievement serialization for Java 21 and expand achievement persistence and reward handling.
- Use the H2 driver explicitly for the recently played cache and initialize the cache with every main database backend.
- Wait for TAB player readiness before applying tab and scoreboard features.

## Installation and upgrade

1. Back up your plugin configuration, arena files and databases.
2. Stop the server and replace the old plugin JAR with `BedWars-5.0.1.jar`.
3. Use Java 21 and keep the required TAB plugin installed.
4. Start the server and test a match, achievement saving and chest deposits.

For chest text close to the chest, set `resource-chest.hologram.y-offset: 0.04`.
Existing configuration values are preserved. Save edits and run
`/bw reload resourcechest` to apply later hologram changes without restarting.
See [resource chest configuration](../resource-chest.md).

## Validation and compatibility

The release is built with JDK 21. Build checks load the bundled, relocated NBT
classes in isolation. Targeted regression checks cover chest ownership and item
conservation, hologram positioning and reloads, serialization and TAB lifecycle.
These checks do not replace a live server test. The reported deployment target
is PandaSpigot 1.8.8 with Java 21; the additional version adapters are included,
but this release has not been play-tested on every supported server version.
